
# AI Mock Interview

AI-powered web platform for practicing IT job interviews.

## Project Description

AI Mock Interview helps users prepare for real IT interviews
through AI-generated questions, interactive conversations,
personalized feedback, and progress tracking.

## Features

- User registration and login
- IT specialization and technology selection
- Company-specific interview preparation
- AI-powered mock interviews
- Question database and reuse
- Interview history
- AI evaluation and recommendations
- Progress tracking

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA

### Database
- PostgreSQL

### AI
- Spring AI
- OpenAI API
